# 配色设计技能包

一组面向 Codex 的中文配色设计技能，用于将色彩意图、版面层级、照片、可读性与系列系统转化为可执行的设计判断。

## 包含的技能

- peise-intent-planner：建立配色简报与目标印象。
- peise-hierarchy-auditor：检查颜色层级与视觉重点。
- peise-multicolor-organizer：整理复杂的多色页面。
- peise-photo-director：协调照片、背景、文字与强调色。
- peise-readability-repair：修复文字与背景的可读性问题。
- peise-series-system：建立统一且可变化的系列化配色系统。

## 使用

在 Codex 的“技能”入口中导入所需的单个技能文件夹。目标印象尚未确定时，先使用 peise-intent-planner。
